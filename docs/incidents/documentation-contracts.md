## 2026-07 - 文件契約與提案邊界

### 經驗

- 對跨 execution world 的擴充功能，應以凍結的來源到文件契約持續驗證目前行為。
- 實作變更時補齊架構說明，並把尚未實作的整合設計明確標示為提案。
- 文件契約不得記錄使用者資料、工作階段識別或不必要的執行期細節；在此前提下以自動檢查防止文件漂移。

### 本次索引化後的維護方式

- [`../error_experience.md`](../error_experience.md) 僅保留反覆可用的觸發／風險、不可違反規則、常見錯誤做法、必要驗證提醒與 incident 連結。
- 日期、版本、測試計數、CDP/session、DOM 座標、事故敘事、失敗嘗試與一次性限制只留在本目錄的專題文件。
- 新事件先判斷是否能補強既有規則；只有需要保留追查脈絡時才建立或擴充 incident，並同步更新[事故總表](README.md)。
